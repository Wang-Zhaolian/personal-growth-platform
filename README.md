# 个人成长平台

一个只供本人使用的中文成长档案云网站。四个模块为每日任务、已完成、进行中和待进行。AI 生成的事项和每日任务先供本人审核，确认后才写入正式记录。手动记录、每日打卡和备份不依赖 AI 服务。

## 模型配置

网页“每日任务 → 设置与数据 → 模型配置”以及各模块的 AI 面板都有模型配置入口。当前支持 [pi-ai](https://github.com/earendil-works/pi/blob/main/packages/ai/README.md) 所列的智谱 GLM Coding Plan、千问 Token Plan 和 Kimi For Coding 订阅服务令牌。选择服务和模型、保存令牌、点击“选用此模型”，再点击“测试连接”完成一次实际模型调用。服务商可能限制可用模型，请以实测为准。

**ChatGPT Plus 尚未接通。** pi-ai 的 OAuth 流程需要 Node 环境；当前 Sites 网站在 Worker 上运行，无法直接完成该登录流程。网页不要求填写 ChatGPT 密码，也不把 Plus 订阅当成普通 API 余额。若要在不用本机助手的前提下使用 Plus，下一步需要可部署的云端 Node 授权和推理服务，并在实际账号上验证登录与模型调用。不会自动启用单独计费的 API。

订阅令牌只会提交到站点服务端，以 AES-GCM 加密后存入云数据库；站点环境中的 `MODEL_CREDENTIAL_KEY` 为独立密钥，不进入源码或 JSON 备份。模型配置也不导出到备份。AI 请求只发送本次生成所需的叙述和相关事项，输出仍需人工审核。若模型未连接或服务故障，手动功能仍可使用。

## 使用与数据

Windows 桌面“个人成长平台”快捷方式只打开云网站，无需启动本机程序。换电脑后登录同一网站即可查看成长记录。本站为本人访问控制，源码保存在私有 GitHub 仓库，实际成长数据保存在 D1 云数据库。

JSON 备份包含事项、草稿、变更历史、每日计划、习惯、打卡及纠错事件。第一版只允许恢复到空数据库，不覆盖已有数据；旧版 v1 备份可导入。建议定期下载并保存到自己控制的位置。

## 本地开发

需要 Node.js 22.13 或更高版本。运行 `npm ci` 安装依赖，`npm run db:generate` 更新 D1 迁移，`npm run build` 构建站点。Sites 发布时应用 `drizzle` 中尚未执行的迁移。

站点配置位于 `.openai/hosting.json`。生产环境的 `MODEL_CREDENTIAL_KEY` 应是随机生成的 32 字节密钥的 Base64 字符串，以 Sites secret 存储；不得提交仓库。部署身份和 D1 绑定由 Sites 管理。
