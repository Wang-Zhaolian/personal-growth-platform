# 个人成长平台

一个只供本人使用的中文成长档案网站。网站和成长数据在云端；Plus AI 使用单独的 Windows 本机助手，通过 Sign in with ChatGPT 订阅授权调用，不使用单独计费的 API key。

## 四个模块

- **每日任务**：按当天可用时间和重点生成建议；人工审核后确认。任务可以部分打卡，纠错会重新计算进度。未完成的项目工作可以在后续日期重新推荐，不会自动确认。
- **已完成**：浏览课程、技能、科研、竞赛、实习及其他成果，可新增、手动修改或使用 AI 整理。
- **进行中**：查看截止日期、逾期/临期状态、优先级、工作量、进度和关联步骤；达到 100% 时由本人核对后确认完成。
- **待进行**：维护未来目标与计划，可让 AI 建议拆分目标和步骤。

AI 生成的变化先显示在预览草稿中。只有在网页确认后才写入正式记录；冲突、重复请求或未解决的问题不会静默覆盖数据。暂停事项不会进入新建议；归档事项默认隐藏。每日习惯单独打卡，不计入项目进度，也不累积漏打卡。

## 使用与 Plus 连接

在 Windows 桌面点击“个人成长平台”快捷方式，或在浏览器打开部署网址。快捷方式会检查并启动本机助手，然后打开云端网站。第一次使用 AI 时：

1. 安装 Node.js 22.13 或更高版本。
2. 启动快捷方式后，在网页的 AI 面板打开本机助手。
3. 在本机助手点击 **Continue with ChatGPT**，登录并明确允许使用 ChatGPT 订阅额度。
4. 将本机助手显示的一次性验证码填入网站 AI 面板并配对，再刷新账号模型列表。

浏览器如果询问网站能否访问本机网络，请允许访问本机 AI 助手。

每台 Windows 电脑需单独完成一次连接和配对；正式成长数据仍保存在同一个云端数据库。授权凭据以 Windows DPAPI 加密保存在当前用户的本机应用数据目录，不进入网站、源码仓库或 JSON 备份。Plus 可用额度由 ChatGPT 账号和 OpenAI 决定，所有使用订阅额度的应用共用账号限额。授权后仍需成功完成一次 Responses 请求，才能算 AI 链路可用。

AI 不可用时，浏览、手动新增与修改、每日任务审核、打卡和备份仍可使用。AI 只处理本次请求所需的叙述与事项；结果先在网页审核，不会直接提交记录。

## 数据、隐私与备份

源码仓库与个人记录分开保存。主平台应放在私有 GitHub 仓库；通用本机助手单独发布其源码，不包含个人记录、OAuth 凭据、网站仓库或账号信息。

设置中的 JSON 备份包含事项、草稿、变更历史、每日计划、习惯、打卡及纠错事件。第一版只允许恢复到空数据库，不会覆盖已有数据；旧版 v1 备份可导入。建议每周下载并存放在自己控制的位置。

## 本地开发

需要 Node.js 22.13 或更高版本。用 npm ci 安装锁定依赖，npm run db:generate 更新 D1 迁移，npm run build 构建站点。Sites 在发布时应用 drizzle 目录中未执行的迁移。

环境配置位于 Sites 项目的 .openai/hosting.json；部署身份和 D1 绑定由 Sites 管理，不要在仓库中提交密钥或真实成长记录。

## 本机助手

assistant 目录包含 Windows loopback 服务：仅监听 127.0.0.1，限制配对网站来源，不接触 D1，也没有正式记录提交接口。其独立使用说明和 MIT 许可位于该目录。每台新电脑按其 README 配置 GROWTH_SITE_ORIGIN 后，可单独启动。
